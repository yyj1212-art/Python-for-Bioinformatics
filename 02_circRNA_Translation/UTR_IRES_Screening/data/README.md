# UTR–IRES Screening — Data

This folder contains the quantitative data extracted from the uploaded experimental screenshots.

## Files

- `01_initial_screening_raw_luminescence.csv`
  - Raw Firefly and Gaussia luminescence values shown in Table 4.
- `02_initial_screening_summary.csv`
  - Initial screening normalized to FHB = 100, with the reported SD values from Table 5.
- `03_repeat_screening_values.csv`
  - Individual normalized values visible in the repeat-experiment data table.
- `04_repeat_screening_summary.csv`
  - Repeat screening normalized to FHB = 100, with the reported SD values from Table 8.
- `05_initial_vs_repeat_comparison.csv`
  - Direct comparison of the two reported mean values (260626 vs 260702), based on the summary tables.

## Conditions

FHB, EVB80, Echo20, Echo26, Echo33, FMDV (A/O), CVA3, CVA7, CVA9, CVA12, CVA17, CVA19, CVB5

## Notes

- Values were transcribed from the uploaded screenshots without adding measurements that were not visible.
- The screenshots use FHB as the reference condition (100).
- `03_repeat_screening_values.csv` contains the replicate values that were visible in the uploaded table; where raw FHB replicate values were not shown, they are not reconstructed.
- The 260626 and 260702 labels are preserved in the comparison file according to the uploaded tables/graphs.
