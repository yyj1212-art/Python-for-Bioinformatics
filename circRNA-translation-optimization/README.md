# circRNA Translation Optimization

This project documents a staged experimental strategy for optimizing protein translation from engineered circular RNAs (circRNAs).

## Project structure

```text
circRNA-translation-optimization/
│
├── README.md
├── 01_IRES_screening/
├── 02_UTR_screening/
└── 03_Integrated_optimization/
```

### 01 — IRES screening

Systematic screening of candidate internal ribosome entry sites (IRESs), followed by repeat screening and comparison of screening performance across experiments.

### 02 — UTR screening

Reserved for subsequent UTR optimization experiments.

### 03 — Integrated optimization

Reserved for combining the optimized IRES and UTR elements into an integrated circRNA translation design.

## Current status

The IRES screening stage is the first populated section. Experimental measurements are kept as data files, while analysis and figures are separated from the underlying measurements to make the workflow easier to reproduce and review.
