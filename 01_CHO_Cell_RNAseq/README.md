# CHO Cell RNA-seq Analysis

Analysis of CHO cell transcriptome data using Python-based bioinformatics workflows.

## Analysis Overview

- RNA-seq count data preprocessing
- Gene expression filtering
- Differential expression analysis
- Visualization
- Gene Ontology enrichment analysis
- Biological interpretation

## Tools

- Python
- Pandas
- NumPy
- SciPy
- Matplotlib
- Seaborn
- gseapy
